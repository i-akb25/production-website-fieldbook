# Operational templates

Copy a template into the consuming project's governance or documentation area. Do not edit the canonical blank merely to make one project pass.

Every `<!-- REQUIRED: ... -->` marker needs an approved answer, an explicit `Not applicable` with rationale and owner, or a release-blocking ticket. Empty fields are not evidence.
