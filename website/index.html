The principle

Claims need evidence.

A green deployment badge is not proof of safe access control, meaningful consent, accessible journeys, or recovery under failure. Fieldbook keeps those responsibilities visible, with people accountable for the final decision.

01 / DEFINE

Make requirements explicit

Document behavior, privacy constraints and applicable release controls while changes are still inexpensive.

02 / VERIFY

Attach actual evidence

Link tests, observations, owners and exceptions to what was really checked, not what was assumed.

03 / RELEASE

Keep human authority

Surface unresolved risks and obtain accountable sign-off. Tooling supports the decision; it does not certify it.

Start with the repository

Adopt only what applies.

The command-line tool is an early preview in the repository. It is not published to npm yet. Run it from a checkout, then complete the manual release record.

# from the repository root
node packages/cli/bin/fieldbook.mjs init
node packages/cli/bin/fieldbook.mjs check
node packages/cli/bin/fieldbook.mjs report --json

No account. No database. No telemetry. No certification claims. The book remains the editorial authority.
