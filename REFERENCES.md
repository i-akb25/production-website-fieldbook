# Authoritative references

Use primary sources, record the exact version and review date, and revalidate applicability before launch. A reference here does not create certification or endorsement.

- Accessibility: [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)
- Web performance: [web.dev Core Web Vitals](https://web.dev/articles/vitals)
- Application security: [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/)
- Web risks: [OWASP Top 10](https://owasp.org/www-project-top-ten/)
- API risks: [OWASP API Security Top 10](https://owasp.org/API-Security/)
- Defensive implementation: [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/)
- Secure development: [NIST Secure Software Development Framework](https://csrc.nist.gov/pubs/sp/800/218/final)
- Secure by design: [CISA Secure by Design](https://www.cisa.gov/securebydesign)
- Incident response: [NIST Incident Response Recommendations](https://csrc.nist.gov/pubs/sp/800/61/r3/final)
- Hacked-site response: [Google Search Central](https://developers.google.com/search/docs/monitor-debug/security/hacked-sites)
- India privacy: [Ministry of Electronics and Information Technology](https://www.meity.gov.in/)
- European Union privacy: [General Data Protection Regulation](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng)
- United Kingdom electronic communications: [ICO PECR guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guide-to-pecr/)
- California privacy: [California Attorney General CCPA guidance](https://oag.ca.gov/privacy/ccpa)
- Children's privacy in the United States: [FTC COPPA](https://www.ftc.gov/legal-library/browse/rules/childrens-online-privacy-protection-rule-coppa)
- Payments: [PCI Security Standards Council](https://www.pcisecuritystandards.org/standards/pci-dss/)
- India payments: [Reserve Bank of India](https://www.rbi.org.in/)
- Platform semantics: [WHATWG HTML Living Standard](https://html.spec.whatwg.org/)
