# Northstar Reading List

**FICTIONAL REFERENCE PRODUCT. NOT A REAL SERVICE. NOT PRODUCTION POLICY.**

Northstar Reading List is a deliberately small example used only to demonstrate how the companion records fit together. It is not based on a real person, company, customer, payment, incident, or private project.

The fictional product shows a public, read-only page that presents a curated reading list from an approved static content file. There is no account, payment, user-submitted content, advertising tracker, or production integration.

Included evidence:

- `page-spec.json`: machine-readable page specification
- `data-inventory.json`: one fictional, minimized operational event
- `component-contract.md`: completed human-readable component contract
- `control-evidence.md`: sample mapping from applicable controls to evidence

The example deliberately says when a decision is unapproved or not applicable. It must not be copied into public legal text or treated as proof of compliance.
